# Biomedical AI Portfolio — Bilingual GitHub Pages

This version includes:
- English / 中文 language switching
- About page with portrait
- Interactive segmentation viewer
- Responsive biotech / medical-AI visual style

## Files
- `index.html`
- `about.html`
- `style.css`
- `script.js`
- `assets/autumn-profile.png`

## Replace these placeholders
- `YOUR_GITHUB_REPOSITORY_URL`
- `YOUR_GITHUB_PROFILE_URL`

## Add the 9 segmentation images to `assets/`
- `failure-original.png`
- `failure-ground-truth.png`
- `failure-prediction.png`
- `typical-original.png`
- `typical-ground-truth.png`
- `typical-prediction.png`
- `strong-original.png`
- `strong-ground-truth.png`
- `strong-prediction.png`

The interactive viewer shows a CSS fallback until those images are added.

## Language behavior
English is the default. The selected language is saved in the visitor's browser using localStorage.
