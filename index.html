01 · PROBLEM

Clinical texture is noisy. Lesion boundaries are not.

Breast ultrasound contains weak boundaries, speckle noise, annotations, and high-contrast structures that can distract segmentation models.

A

Reproducible pipeline

Fixed stratified split, PyTorch Dataset/DataLoader, train/evaluate/predict scripts, and saved inference configuration.

452train 97validation 98test

Model capacity became the decisive bottleneck.

B

Loss diagnosis

BCE-only training collapsed toward background.

C

Error analysis

Failure cases revealed responses to high-contrast tissue structures and annotations rather than lesion shape alone.
